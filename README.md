This Repo consists of the designs I usually draw UML diagrams.
I am not going to develop anything instead I desgin the systems.
This helps me to think about the system.


## Component relation:
1. Dependency (Uses-A): A dashed arrow pointing to the used class.
2. Association (Has-A): A simple solid line connecting classes.
3. Aggregation: A solid line with an unfilled diamond pointing to class.
4. Composition: A filled diamond pointing toward the class.
5. Generalization/Inheritance (Is-A): A unfilled triangular arrowhead to the parent.
6. Realization: A hollow triangular arrowhead pointing from the class to the interface.

## Notes:
Every Aggregation is an Association, but not every Association is an Aggregation.
Aggregation is just a stricter, more descriptive sub-type of Association.
